# TikTok_Video_Data_Regression_Analysis

## Overview: 

##### TikTok is working on a machine learning model that will catergories videos based on claims and opinions. During my hypothesis test, I found that unverified accounts recieve more views on their videos compared to verified users. In this project I created a logisitic regression model that predicts the verification status (verified/ unverified). 


## Methodology 

##### A logisitic regression model was created to predict the verified status of TikTok users.

## Key Insights: 
- The logisitic regression model had imperfect, but acceptable predicitive power. The model achieved:
  - precision: 69%
  - recall: 66%
  - f1 accuracy of 66%.
 
- Based on the model coefficients, verified users tend to be connected to longer videos. Other variables have weaker correlations with the verified status.
